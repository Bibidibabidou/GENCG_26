## A Lexicon of Remembered Things

_Turning written memories into a generative visual language_

**Starting point**  
Short written memories: my own writing, plus memories collected from others (content that resonate with me). Each memory is a few sentences describing a place, a gesture, an object or a person. The starting point doesn’t have to be visible in the final work, but it shapes everything.

**Concept**  
Memories are already a translation: something lived becomes words. This project adds more translations: **text → symbols → code → image**. Each step interprets the one before it, and something is lost or changed each time, just like memory itself. The work asks: what survives when a memory passes through a system, and how differently do people read the same memory?

**Inspiration**  
Zarina Hashmi turned home and displacement into a minimal vocabulary of signs, one word paired with one image (_Home Is a Foreign Place_). Mark Webster puts the human hand back into generative systems instead of relying on randomness. My project builds a shared vocabulary from many people’s memories rather than one person’s, and makes the act of interpretation itself visible.

**System**

1. **Collect:** gather 10–20 short written memories.
2. **Describe & extract:** pick key words and simple data from each text (places, objects, actions, length, rhythm).
3. **Symbol vocabulary:** design a set of minimal symbols, partly hand-drawn, for recurring ideas (_door, road, water, leaving, voice_). Words become symbols.
4. **Composition rules in p5.js:** the order, frequency and length of words decide where symbols go, how big they are, and how stable they look. The text appears alongside or dissolves into the image.
5. **Comparison:** the same memory can be interpreted by different rule sets, or by different people, to show how meaning shifts.

**Form**  
A webpage gallery: each memory becomes a small animated or static “plate,” with the text revealed slowly. Viewers can switch between the original text and its symbolic version.

**Tools**  
p5.js for the symbol system and animation; Obsidian/Excalidraw for designing the vocabulary; AI possibly tested at one step (e.g. comparing a model’s image of a memory with my symbolic one).

**Prototype for next session** 
Three memories, a first set of 5–8 symbols, and one working rule linking words to symbol placement.

**Open questions**

- How literal or abstract should the symbols be?
- Should the original text stay readable?
- Who interprets: me, the system, or the viewers?

**Working title options:** _A Lexicon of Remembered Things_ · _Foreign Words for Home_ · _What Remains_
